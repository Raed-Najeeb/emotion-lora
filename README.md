# Emotion Classification: Full Fine-Tuning vs. LoRA

A comparative study of full fine-tuning and Low-Rank Adaptation (LoRA) for six-class emotion classification using DistilBERT and the Hugging Face ecosystem.

## Overview

This project compares two approaches to adapting a pretrained language model for text emotion classification:

- **Full fine-tuning:** updates the model's parameters during training.
- **LoRA fine-tuning:** freezes the pretrained weights and trains low-rank adapters alongside the classification head.

Both approaches use the same pretrained model, dataset splits, evaluation metrics, and three-epoch training schedule.

## Dataset

**Dataset:** [dair-ai/emotion](https://huggingface.co/datasets/dair-ai/emotion)

The dataset contains English text labeled with six emotions:

- Sadness
- Joy
- Love
- Anger
- Fear
- Surprise

| Split | Examples |
|---|---:|
| Training | 16,000 |
| Validation | 2,000 |
| Test | 2,000 |
| **Total** | **20,000** |

Text was tokenized using the DistilBERT tokenizer, with truncation at a maximum sequence length of 128 tokens.

## Model and Training Setup

- **Base model:** `distilbert/distilbert-base-uncased`
- **Framework:** PyTorch and Hugging Face Transformers
- **Hardware:** NVIDIA GeForce RTX 5050 Laptop GPU
- **Epochs:** 3
- **Training batch size:** 16
- **Evaluation batch size:** 32
- **Precision:** FP16
- **Model selection:** best validation macro F1
- **Random seed:** 42

### LoRA configuration

| Parameter | Value |
|---|---|
| Rank (`r`) | 8 |
| Alpha | 16 |
| Dropout | 0.1 |
| Target modules | `q_lin`, `v_lin` |
| Trainable classification modules | `pre_classifier`, `classifier` |
| Learning rate | 2e-4 |

The full fine-tuning baseline used a learning rate of 2e-5.

## Results

Both models were evaluated on the held-out test split.

| Metric | Full fine-tuning | LoRA |
|---|---:|---:|
| Accuracy | **93.15%** | 91.65% |
| Macro precision | **90.54%** | 87.24% |
| Macro recall | 87.65% | **88.33%** |
| Macro F1 | **88.86%** | 87.71% |
| Training time | ~91 sec | ~66 sec |

*Training times are from individual runs and may vary with system conditions.*

### Parameter efficiency

The LoRA model contains 67,700,748 total parameters, of which 742,662 were trainable.

**Only 1.10% of the model's parameters were trainable during LoRA fine-tuning.**

In these runs, LoRA also took less training time, while full fine-tuning achieved higher test accuracy and macro F1.

## Key Takeaways

1. Full fine-tuning achieved stronger overall test performance in this experiment.
2. LoRA reduced the number of trainable parameters substantially.
3. Macro recall and macro F1 provide complementary information, particularly when emotion classes have different frequencies.
4. Parameter efficiency and predictive performance are different objectives; the best approach depends on the constraints of the application.

## Experimental Limitations

- The two experiments used different learning rates, so the results do not isolate the effect of the fine-tuning method alone.
- Training times come from single runs and are not controlled benchmarks.
- The dataset inspection identified some exact-text overlap across the published splits. This should be investigated and documented before treating the results as a definitive generalization benchmark.
- Results reflect one random seed and one configuration per method; repeated runs and hyperparameter tuning could change the comparison.

## Run the Experiments

Create and activate a Python virtual environment, then install the required dependencies:

```bash
python -m pip install torch transformers datasets scikit-learn accelerate peft
```

Run dataset inspection:

```bash
python src/inspect_data.py
```

Run full fine-tuning:

```bash
python src/train_baseline.py
```

Run LoRA fine-tuning:

```bash
python src/train_lora.py
```

The training scripts save evaluation metrics under `results/` and trained model artifacts under `models/`.
